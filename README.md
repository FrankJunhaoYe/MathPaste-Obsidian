# MathPaste

面向 Windows 版 Obsidian 的本地公式定界符转换插件。将复制文本中的 `\(...\)` 转为 `$...$`，将 `\[...\]` 转为 `$$...$$`，保留公式内部的 LaTeX 内容。不需要账号、密钥或服务器。

**当前状态：0.1.0 开发试用版，已接入手动命令、自动粘贴和一个设置开关，可在专用测试库试用。** Windows Obsidian 1.14.4 已验证命令、实际文本粘贴及撤销/重做；完整 P5 验收尚未完成。证据及待验证范围见 [宿主验收记录](docs/host-validation.md)。尚未发布正式版本或上架社区插件。

## 转换示例

行内公式：

```text
转换前：由 \(x^2 + y^2 = z^2\) 可知……
转换后：由 $x^2 + y^2 = z^2$ 可知……
```

用户提供的独立公式，转换前：

```latex
\[
\boxed{\bar X\approx N\left(\mu,\frac{\sigma^2}{n}\right)}
\]
```

转换后：

```latex
$$
\boxed{\bar X\approx N\left(\mu,\frac{\sigma^2}{n}\right)}
$$
```

这里的代码围栏仅用于展示输入与输出；插件跳过实际笔记里的代码区域。

## 使用与安装

先使用空白测试库，并保留需要测试文本的副本。当前最低版本声明为实测的 Obsidian 1.14.4，仅以 Windows 为验收范围；其他版本尚未验证。

1. 从源码构建，或使用本次交付的本地试用包。将 `main.js`、`manifest.json` 放入测试库的 `.obsidian/plugins/mathpaste/`。当前不需要 `styles.css`，不要安装开发探针。
2. 在 Obsidian 的第三方插件页面启用 MathPaste。默认开启自动转换。
3. 在 Markdown 编辑器的源码模式或实时预览模式粘贴含有完整源定界符的文本。安全匹配时直接插入转换结果，没有匹配时使用默认粘贴。
4. 手动转换：按 `Ctrl+P`，选择 **MathPaste：转换公式定界符（选区或当前笔记）**。有选区时只处理完整落在选区内的公式，无选区时处理当前笔记。可在快捷键设置中自行绑定，插件不预设快捷键。
5. 在 **设置 → MathPaste → 自动转换粘贴内容** 关闭自动转换后，仍可使用手动命令。设置仅在保存成功后生效，保存失败会提示并恢复开关。
6. 有效转换可通过 `Ctrl+Z` 一次撤销，`Ctrl+Shift+Z` 重做。没有变化时不新增编辑记录。

卸载时先禁用 MathPaste，再删除测试库中的 `.obsidian/plugins/mathpaste/` 文件夹。不要删除笔记。日常库安装需另行决定，本项目没有自动安装到日常库。

## 使用限制

- 命中公式时读取 `text/plain` 并按纯文本插入，**仅存在于 HTML 中的富文本格式会丢失**。需要保留富文本时，先关闭自动转换，再粘贴并按需运行命令。若剪贴板已丢失 LaTeX 源码，插件无法还原公式。
- 文件或图片载荷、其他插件已处理的粘贴、多光标、无匹配或不安全上下文均交回默认行为。原生图片、附件和外部富文本的完整人工验收仍待完成。
- 代码、已有美元数学、YAML、链接目标及部分不完整结构保守跳过。歧义配对、跨行行内公式不转换；不修复公式，不额外给同行独立公式加换行。
- 同步处理限全文 32,768 个 UTF-16 代码单元、单行 2,048 个、结构标记 2,048 个。超过上限，手动命令提示并保持原文，自动转换交回默认粘贴。选区很小时也须检查完整笔记。
- 只支持一个选区。保护规则覆盖当前测试样例，不承诺识别所有 Obsidian 扩展语法；实时预览的 YAML 属性面板尚未直接验收。

## 本地开发

使用 Node.js 24.13.0 和 npm 11：

```powershell
npm ci
npm run check
```

`npm run dev` 监听构建，`npm run build` 生成 `main.js`。开发探针单独构建，不进入产品包。构建成功不代表所有宿主行为通过。完整命令与协作方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
