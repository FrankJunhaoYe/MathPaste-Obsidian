# MathPaste

面向 Windows 版 Obsidian 的公式定界符转换插件项目：计划将复制文本中的 `\(...\)` 转为 `$...$`，将 `\[...\]` 转为 `$$...$$`，保留公式内部的 LaTeX 内容。

**当前状态：工程已初始化，公式转换功能尚未实现，也未发布可用版本。**

## 转换示例

行内公式：

```text
转换前：由 \(x^2 + y^2 = z^2\) 可知……
转换后：由 $x^2 + y^2 = z^2$ 可知……
```

用户提供的独立公式，转换前：

```latex
\[
\boxed{\bar X\approx N\left(\mu,\frac{\sigma^2}{n}\right)}
\]
```

转换后：

```latex
$$
\boxed{\bar X\approx N\left(\mu,\frac{\sigma^2}{n}\right)}
$$
```

这里的代码围栏仅用于展示输入与输出；计划中的插件应跳过实际笔记里的代码区域。

## 第一版计划

- 在 Markdown 编辑器中粘贴文本时自动转换成对的公式定界符。
- 提供手动命令：有选区时转换选区，无选区时转换当前笔记；用户可自行绑定快捷键。
- 跳过代码块和行内代码，保留已有 `$...$`、`$$...$$`。
- 保留公式内部命令、空白与换行；支持正常撤销。
- 完全本地处理，不需要 ChatGPT 账号、API Key 或服务器。

以上是计划和验收目标，不代表功能已实现。第一版仅以 Windows 桌面环境作为支持和验收范围。

## 本地开发

使用 Node.js 24.13.0 和 npm 11：

```powershell
npm ci
npm run check
```

`npm run dev` 监听构建，`npm run build` 生成 `main.js`。当前入口为空，不提供转换功能；构建成功不代表已经完成 Obsidian 内加载或功能验证。完整命令与协作方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
