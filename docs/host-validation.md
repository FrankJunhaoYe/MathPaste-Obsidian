## 已实现的行为

`src/main.ts` 注册一个命令、一个粘贴监听和设置页。编辑器扩展通过公开 `editorInfoField` 取得 Editor 与 CodeMirror 视图的对应关系；仅在 Markdown 编辑视图执行。未使用宿主私有字段。

`src/editor.ts` 先验证单选区和文档一致性，再调用纯转换规划。有效修改以一次事务提交，隔离前后撤销历史，映射选区；无变化时不 dispatch。自动粘贴只读取本次事件的 `text/plain`，仅在安全匹配时阻止默认粘贴，无成功弹窗。文件/图片载荷、已处理事件、关闭开关、多选区和超限输入不拦截。

设置默认开启，只接受持久化数据中的布尔值。保存成功后更新运行时偏好；保存失败时恢复开关并提示。监听使用 `registerEvent`，编辑器扩展在销毁时移除视图，卸载后回调不执行转换；等待设置加载期间卸载也不会迟到注册事件。

## 证据类型

1. **自动测试**：`npm run check` 通过，9 个测试文件、130 项测试。编辑事务测试使用真实 CodeMirror State/history/undo/redo；宿主注册、设置 UI 和存储失败使用模拟 Obsidian 对象，不能代替真实界面重载与禁用测试。
2. **真实宿主、合成事件**：独立 `scripts/host-probe.ts` 在 Obsidian 内创建笔记，通过公开 Editor/CodeMirror API 执行选区、撤销和重做，通过 `workspace.trigger('editor-paste', ...)` 进入实际产品监听。DataTransfer 含已知纯文本和合成 HTML；不是系统可信粘贴事件，不代表外部软件复制流程或附件默认插入的完整验证。
3. **原生键盘操作**：2026-10-22 在测试库通过命令面板运行实际产品命令；实时预览中使用 Ctrl+C/Ctrl+V，随后 Ctrl+Z/Ctrl+Shift+Z。检查编辑器和保存到磁盘的文本。没有通过插件改写系统剪贴板。

## 实时预览 YAML 的特殊情况

本地 `mathpaste-host-enabled.json` 中 `live.defaultInyaml` 原始值为 false，不能将整份报告声称为“全绿”。请求在 15 字符 YAML 内偏移 8 放光标，宿主隐藏属性并补一个换行，将实际光标移至偏移 16，即属性外。随后转换发生在普通正文位置，输入长度从 16 变为 19；这并非观察到 YAML 内容被修改。

探针现已补充实际选区检查：宿主移动光标时，将该项记录为 `not-exercised-host-relocated-cursor`，另检查正文插入。此诊断修订尚未重新执行。源码模式 YAML 内光标仍为偏移 8，不拦截且文本不变的检查已通过。**实时预览属性面板内部尚未直接测试。**

## 复现开发探针

先运行 `npm ci` 与 `npm run check`。新专用库可通过 `npm run p1:prepare -- <新测试库绝对路径>` 初始化；它保留历史 P1 探针。对已有、带正确标记的测试库，运行：

```powershell
node scripts/prepare-host-probe.mjs 'D:\AppsData\MathPaste\P1-Source-20261019'
```

这只更新已标记库中已安装的产品和开发探针，不创建新的全局配置。探针生成 `mathpaste-host-enabled.json` 或 `mathpaste-host-disabled.json`；文件存在时不重复运行。保留并重命名旧报告后，通过该测试库的命令面板选择“重新加载 Obsidian”再运行。报告应检查 `error`、每项布尔值和跳过说明，不能只检查文件存在。合成事件未拦截时不会模拟 Obsidian 的后续默认插入，因此只证明产品不接管该事件。
