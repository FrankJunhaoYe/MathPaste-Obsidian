## 基础文本用例

| 编号 | 输入                       | 预期输出               |
| ---- | -------------------------- | ---------------------- |
| T01  | `\(x^2 + y^2\)`            | `$x^2 + y^2$`          |
| T02  | `\[E = mc^2\]`             | `$$E = mc^2$$`         |
| T03  | `由 \(a\) 和 \(b\) 可得。` | `由 $a$ 和 $b$ 可得。` |
| T04  | `$x^2$` 与 `$$E = mc^2$$`  | 保持原样               |
| T05  | `\(x + 1` 或 `x + 1\)`     | 保持原样               |
| T06  | 普通中文、英文、价格和标点 | 保持原样               |

T07：用户提供的多行公式。

输入：

```text
\[
\boxed{\bar X\approx N\left(\mu,\frac{\sigma^2}{n}\right)}
\]
```

预期：

```text
$$
\boxed{\bar X\approx N\left(\mu,\frac{\sigma^2}{n}\right)}
$$
```

核对内部内容逐字一致；同时检查 LF 与 CRLF 输入的换行保留情况。

## 保护与边界用例

- [x] T08：行内代码中的 `\(x\)` 和 `\[y\]` 保持原样，包括多反引号包裹的代码。
- [x] T09：反引号围栏、波浪线围栏和缩进代码块中的示例保持原样；代码块外的正常公式仍转换。
- [x] T10：已有 `$...$`、`$$...$$` 内部出现类似定界符时，已有数学区域整体保持原样。
- [x] T11：单次输入混合中文、普通段落、多个公式和代码时，只有目标区域变化。
- [x] T12：同一结果再次转换，无额外变化。
- [x] T13：未配对、交叉、嵌套和重复转义样例按需求文档的保守规则跳过；开发前补齐具体样例。
- [x] T14：选区只覆盖代码或已有数学区域的一部分时，依据完整笔记上下文跳过。
- [x] T15：空文本、无公式文本不会触发额外编辑。
