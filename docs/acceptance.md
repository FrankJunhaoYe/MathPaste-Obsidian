- [ ] T08：行内代码中的 `\(x\)` 和 `\[y\]` 保持原样，包括多反引号包裹的代码。
- [ ] T09：反引号围栏、波浪线围栏和缩进代码块中的示例保持原样；代码块外的正常公式仍转换。
- [ ] T10：已有 `$...$`、`$$...$$` 内部出现类似定界符时，已有数学区域整体保持原样。
- [ ] T11：单次输入混合中文、普通段落、多个公式和代码时，只有目标区域变化。
- [ ] T12：同一结果再次转换，无额外变化。
- [ ] T13：未配对、交叉、嵌套和重复转义样例按需求文档的保守规则跳过；开发前补齐具体样例。

- [ ] T15：空文本、无公式文本不会触发额外编辑。
